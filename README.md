# 📊 JobScope — Job Market Analyzer

## About the Project

JobScope is a beginner-friendly data analysis project built using Python Pandas and Matplotlib.

It analyzes job listings to identify in-demand skills, job locations, and salary trends.

## Features

* Total job listing analysis
* Job title analysis
* Location-wise job analysis
* Technical skills demand analysis
* Average salary comparison
* Highest-paying job listing
* Python-related job filtering
* Data visualization using charts

## Technologies Used

* Python
* Pandas
* Matplotlib
* CSV

## Project Files

| File                 | Description          |
| -------------------- | -------------------- |
| `job_data.csv`       | Job listing dataset  |
| `main.py`            | Python analysis code |
| `skill_demand.png`   | Skill demand chart   |
| `average_salary.png` | Average salary chart |

## Installation

Install the required libraries:

```bash
python -m pip install pandas matplotlib
```

## How to Run

Run this command in the project directory:

```bash
python main.py
```

## Dataset Disclaimer

The initial dataset contains fictional sample job listings for educational purposes. Results do not represent actual job-market statistics.
